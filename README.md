# ❄️ Winter Holiday Adventure Game – Winter Code Sprint ⛄

## Sample Map (Example Winter World)

Below is a simple 7-location winter adventure map your team may use or modify:

```
           [Crystal Peak]
                 |
     [Frozen Lake] --- [Snowy Forest]
           |                 |
      [Cozy Cabin] ---- [Holiday Market]
                 \        /
               [Toy Workshop]
```

### **Locations & Notes**

- **Cozy Cabin** — Starting point; contains cocoa + scarf.
- **Frozen Lake** — Slippery crossing; meet a snowman who gives clues.
- **Crystal Peak** — High mountain; requires warm clothing.
- **Snowy Forest** — Magical animals live here; find snowshoes.
- **Holiday Market** — Buy or trade items.
- **Toy Workshop** — Meet the Toymaker; major quest item located here.

## 🗓️ 3-Day Sprint Checklists

### **Day 1 — Brainstorming + Planning (Majority of the Day)**  
**Goals:** Build the concept, world, and class structure.

**Checklist:**  
- [ ] Choose your winter adventure theme  
- [ ] Decide the player’s main objective  
- [ ] Brainstorm 5–7 locations  
- [ ] Sketch a map (use or adapt the sample map)  
- [ ] Brainstorm characters (3–5)  
- [ ] Brainstorm items (5–8)  
- [ ] Define how items influence gameplay  
- [ ] Decide travel rules (paths, special requirements)  
- [ ] Outline Location, Character, Item, and Player class responsibilities  
- [ ] List properties + methods for each class  
- [ ] Draw a simple class diagram  
- [ ] Plan division of labor for Day 2 coding  

---

### **Day 2 — Coding Core Features**  
**Goals:** Build a playable core game.

**Checklist:**  
- [ ] Implement Location class  
- [ ] Implement Item class  
- [ ] Implement Character class  
- [ ] Implement Player class  
- [ ] Build your map using Location connections  
- [ ] Add items to specific locations  
- [ ] Add characters to specific locations  
- [ ] Implement travel mechanics  
- [ ] Implement item pickup  
- [ ] Implement item use logic  
- [ ] Implement character interaction  
- [ ] Create a main game loop or gameplay sequence  
- [ ] Run small tests after each feature  

---

### **Day 3 — Testing + Polish**  
**Goals:** Fix bugs, refine gameplay, and prepare your presentation.

**Checklist:**  
- [ ] Full team playthrough  
- [ ] Fix broken travel paths  
- [ ] Fix inconsistent item behavior  
- [ ] Balance gameplay (warmth, health, difficulty)  
- [ ] Refine messages / text descriptions  
- [ ] Add at least 1 creative holiday mechanic  
- [ ] Add small enhancements (ASCII art, sound text cues, etc.)  
- [ ] Prepare 1–2 minute informal presentation  
- [ ] Show off map, creative items, and unique interactions
